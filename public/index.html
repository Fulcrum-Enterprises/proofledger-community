Proof of existence, on your own server

This server records the SHA-256 fingerprint of a file on the Polygon blockchain and issues a certificate and a proof bundle. A proof shows that a file with that exact fingerprint existed by the anchor time and has not changed since. It does not show who made the file.

Use the API

curl -X POST /api/v1/proof \
  -H "Authorization: Bearer sk_..." -H "Content-Type: application/json" \
  -d '{"sha256": "<64 hex characters>", "filename": "contract.pdf"}'

Keys are made on the server with proofledger key create <email>. The API is the same as proofledger.io's: POST /api/v1/proof, POST /api/v1/proofs/batch, GET /api/v1/proof/:id, GET /api/v1/proof/:id/bundle, GET /api/v1/proofs, GET /api/v1/verify?hash=, and webhooks under /api/v1/webhooks. Full reference: proofledger.io/api.

Check a proof without this server

Download the bundle, then pip install verify-proof and verify-proof verify <file> --proof bundle.json. The transaction on Polygon carries the hash in its input data; the block time is the anchor time.
